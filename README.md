# Финансовый трекер

Локальное Android-приложение для учёта личных доходов и расходов с копилками, месячным бюджетом, курсами валют НБ РБ, сканированием чеков и приёмом банковских уведомлений. Все данные хранятся **только на устройстве** — никаких серверов и аккаунтов.

## Возможности

**Главная**
- Баланс всех операций, «можно тратить в день» (из месячного бюджета и дней до конца месяца);
- Карточка бюджета с цветным прогресс-баром (зелёный <50% → жёлтый 50–80% → красный >80% израсходованных);
- Карусель копилок с прогрессом к цели;
- Карточки курсов USD/EUR/RUB (НБ РБ) с датой актуальности, тап открывает конвертер;
- Последние 5 операций.

**Операции**
- Добавление расхода/дохода: тип, сумма, категории (живые из БД), дата (Сегодня / Вчера / календарь), комментарий;
- Редактирование и удаление: тап по записи в «Истории»;
- **Сканирование чека**: фото или выбор из галереи → ML Kit OCR (офлайн) распознаёт текст, сумма и дата подставляются в форму полуавтоматически — перед сохранением всё можно поправить;
- **Автозаполнение из банка**: «Поделиться» из пуша любого банка → трекер парсит сумму, дату и предлагает категорию.

**История**
- Листание месяцев, поиск по описанию и категории, фильтры Все/Расходы/Доходы;
- Группировка по дням с итогом расходов за день и итогами месяца.

**Статистика**
- Периоды Неделя / Месяц / Год;
- Итоги периода: расходы (со сравнением «↑ 12% к прошлому месяцу»), доходы и баланс;
- Пончик, график «по дням» и топ категорий — с переключателем **Расходы / Доходы**;
- Всё нарисовано на Canvas, без сторонних графических библиотек.

**Копилки**
- Накопления с целью (процент + прогресс) или без;
- «Отложить» / «Снять» — с валидацией и **автоматической операцией** в общем списке (отложил → расход «Отложено в „...“», снял → доход);
- История движений хранится по каждой копилке.

**Ещё (настройки)**
- Управление категориями: создание/редактирование (иконка, цвет, тип), удаление с предупреждением о связанных операциях, системные категории защищены;
- Бюджет месяца;
- Экспорт отчёта по операциям за месяц в **PDF** (итоги + таблица, отправка через системное «Поделиться»);
- Тема: светлая / тёмная / системная — применяется на лету ко всем экранам;
- Валюта: BYN (по умолчанию), RUB, USD, EUR, PLN, UAH — суммы в БД хранятся в BYN и **конвертируются по курсу НБ РБ** на лету;
- Язык интерфейса: русский / English (per-app locale);
- Переключатель уведомлений.

**Фоновые задачи (WorkManager)**
- Ежедневно в 9:00: проверка бюджета — push при 80% и 100% (канал `budget_alerts`, флаги в БД исключают повтор);
- Ежедневно в 9:00: обновление курсов НБ РБ (плюс при каждом старте и раз в 6 часов пока приложение живо; офлайн — работает на кэше).

## Технологии

- Kotlin, Jetpack Compose (Material 3), Navigation Compose
- Room 2.6 (8 таблиц, миграции, экспорт схем), Hilt 2.51, Coroutines + Flow
- WorkManager + hilt-work, Retrofit + OkHttp + Gson (api.nbrb.by)
- ML Kit Text Recognition (локальное OCR)
- Clean Architecture: `data` / `domain` / `ui`, ViewModel'ы не видят Room-энтити

## Структура

```
app/src/main/java/com/example/finance_tracker/
├── core/            # Инициализация, конвертер валют, уведомления, парсеры, PDF
├── data/
│   ├── local/       # Room: entities, dao, relation, AppDatabase, Converters
│   ├── mapper/      # Entity ↔ Domain
│   ├── remote/      # Retrofit API НБ РБ
│   ├── repository/  # Реализации репозиториев
│   └── work/        # WorkManager-воркеры
├── di/              # Hilt-модули (Database, Network, Repository, WorkManager)
├── domain/          # Модели и интерфейсы репозиториев (чистый слой)
├── presentation/    # ShareReceiverActivity (приём «Поделиться»)
└── ui/              # Compose: navigation, screens, components, theme
```

## Сборка

1. Android Studio (Koala+) или JDK 17;
2. Открыть проект, дождаться Sync (Gradle 8+, AGP из `libs.versions.toml`);
3. `Run ▶` на устройстве/emulator (minSdk 28, targetSdk 35).

Из командной строки:

```bash
./gradlew :app:assembleDebug        # сборка APK
./gradlew :app:compileDebugKotlin   # быстрая проверка компиляции
```

Для сканера чеков и курсов нужен интернет (кэш курсов работает офлайн). Уведомления — выдать разрешение на первом запуске (Android 13+).

## Приватность

Приложение делает ровно один сетевой запрос — курсы валют с `api.nbrb.by`. Операции, копилки, настройки и чеки никуда не отправляются; распознавание чеков выполняется на устройстве.
